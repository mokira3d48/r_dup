## Description

This program allows to remove the files duplicated located
in a selected directory and its sub-directory. 

---

## Usage

```sh
./rdup.py path/to/directory
```

```sh
./rdup.py path/to/directory -r
```

## Features

- Analyse and show the files duplicated
- Remove the files duplicated

## Tests

To execute the unittest, make sure you have `pytest` package installed,
and then run the following command line:

```bash
make test 
```
or

```shell
pytest
```
